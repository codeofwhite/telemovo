# PICO 遥操操作

当前按键是 TeleMovo 实验方案，不是所有机器人通用的“官方标准”。仅控制仿真。
没有把按键映射到录制、任务成功／失败或保存。

## 首次操作

1. 确认页面实时更新，选择“桌面坐标”和“锁定夹爪朝向”，启用方向指南。
2. 双手柄放在头显前，松开双 Grip，自然看前方后点击“进入 VR 遥操”。
3. 先只按住左 Grip，移动约几厘米，确认左臂响应。左侧蓝色，右侧橙色。
4. 松开 Grip，将手柄放回舒适位置，再按住。每次重新按住时以当前位置建立相对锚点。
5. 单独练习 Trigger 开合，然后右臂重复；之后再尝试接近衣物。

## 按键与界面

| 操作 | 效果 |
|---|---|
| 按住左／右 Grip | 对应机械臂跟随相对位移 |
| 松开 Grip | 机械臂保持，允许重新摆放手柄 |
| Trigger | 对应夹爪闭合程度；需要追踪有效并完成松 Grip 解锁 |
| 页面“重置视角” | 发送保持，并在下一帧重新建立头部锚点；先松开双 Grip |
| 页面“重置衣物和双臂” | 恢复出生／初始状态；先松开双 Grip，不会保存数据 |
| 页面“锁定夹爪朝向” | 固定每次 Grip 锚定时的实际夹爪朝向 |
| 页面“跟随手腕旋转” | 相对手柄旋转映射到夹爪；建议先小角度练习 |
| 页面“显示 VR 指标” | 显示性能状态；默认关闭中央指标以减少遮挡 |
| 退出 VR／断连 | 输入失效后停止跟随；重连后先松开双 Grip |

Grip 使用 WebXR `xr-standard` 的 buttons[1]，Trigger 为 buttons[0]，不是 Android 或
普通游戏手柄的按钮编号。控制模式应在双 Grip 松开时切换。

## 方向如何理解

默认桌面坐标使用进入时头部的水平朝向，上下方向保持竖直，不把斜俯视角的俯仰混入
手柄位移。右移对应桌面 X，上抬对应 Z，水平前推对应 Y。当前位移比例为 0.5：
手柄移动 10cm，对应目标移动约 5cm。头部可转动、探身，控制坐标以校准时为准。
需要重新定义朝向时松开双 Grip，再重置视角。

RGB 轴分别是 X 红、Y 绿、Z 蓝。桌面箭头表示工作坐标，夹爪附近坐标轴表示实际 TCP。
目标框和误差线帮助分辨“希望去的位置”与“物理执行到的位置”。不要为追赶误差继续
大幅移动；先松开 Grip，检查工作空间和碰撞。

保留的“原俯视坐标”用于历史对照，不建议作为首次操作默认。头显接近竖直朝上／下时
无法可靠确定水平朝向，系统会要求自然看向前方再校准。

## 布料操作的现实限制

先练空场移动、开合、从悬边下方接近，再尝试单侧轻提和释放。夹爪张开后需要确认
衣物确实脱离；不要把夹爪移动时布料局部跟随等同于可靠抓取。
当前没有辅助抓取、黏附或节点绑定。夹持与折叠尚未稳定，失败时保留现象供诊断。
台边指南分为校准移动、夹爪开合、接近衣物和双臂配合，属于操作提示，不是自动任务规划。
